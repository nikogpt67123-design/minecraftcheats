# Orchard Client Website 🌌

A modern, futuristic, cosmic-themed website built for **Orchard Client** with dynamic galaxy particle physics, glowing neon glassmorphism UI, interactive showcase embeds, accordion FAQ, and clean mobile responsiveness.

> *"Everything Is Easier With Orchard."*

---

## 🚀 Features

- **Cosmic Space & Galaxy Visuals:** Real-time HTML5 Canvas particle/starfield engine with parallax cosmic dust, nebulae, and interactive star acceleration.
- **Glassmorphism & Neon Glow:** Custom cyberpunk / deep cosmic aesthetic using midnight blue (`#030712`), royal electric blue (`#2563eb`), vibrant cyan (`#06b6d4`), and crisp glow borders.
- **Showcase Video Center:** Dual video presentation cards with play preview triggers, modal player support, and customizable embed URLs.
- **Interactive FAQ Accordion:** Smooth keyboard accessible accordion with expandable answers and animated chevron indicators.
- **Quick Deployment Ready:** Pure standard HTML5, CSS3, and JavaScript — zero dependencies, ready for GitHub Pages, Cloudflare Pages, or Vercel.

---

## 🛠️ Configuration

Open `js/config.js` or directly edit `index.html` to configure:
1. **Download Link:** Update `data-download-url` or the `href` in the download buttons.
2. **Discord Server:** Update `data-discord-url` or your Discord invite link.
3. **Showcase Videos:** Replace placeholder URLs in the `iframe` or `data-video-id` attributes.

---

## 🌐 Deploy to GitHub Pages

1. Push this repository or directory to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/root`.
4. Click **Save** — your site will be live instantly!
